# 🛍️ Black Friday Dataset
## EDA & Feature Engineering

End-to-end Exploratory Data Analysis
and Feature Engineering on the
Black Friday sales dataset to prepare
data for machine learning model training.

---

## 📌 Problem Statement

Retail company ABC Private Limited
wants to understand customer purchase
behaviour against various products
across different categories.

---

## 📂 Dataset

- train.csv
- test.csv

Source: Kaggle Black Friday Dataset

---

## 🛠️ Tools Used

- Python 3
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

---

## 📊 EDA Performed

- Data Loading (train + test)
- Dataset concatenation
- Data inspection (info, describe)
- Missing value detection
- Dropping irrelevant features
- Data visualization

---

## ⚙️ Feature Engineering Performed

- Label Encoding (Gender: M/F → 1/0)
- Ordinal Encoding (Age ranges → 1-7)
- One-Hot Encoding (City Category)
- Missing value imputation (mode)
- String to integer conversion
- Feature Scaling (StandardScaler)
- Train Test Split (67/33)

---

## 🔍 Key Insights

- Male customers purchase more than females
- Age group 26-35 has highest purchases
- Product Category 1 is most purchased
- Most customers are from City Category B

---

## 📈 Visualizations

- Age vs Purchase (by Gender)
- Occupation vs Purchase (by Gender)
- Product Category 1, 2, 3 analysis

Train Machine Learning model
