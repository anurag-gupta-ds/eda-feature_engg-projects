# 🚢 Titanic Dataset - Exploratory Data Analysis & Feature Engineering

Exploratory Data Analysis and Feature Engineering
performed on the Titanic dataset to prepare
the data for Machine Learning model training
and survival prediction.

---

## 📌 Objective

To explore and analyze the Titanic dataset
and extract meaningful insights about:

* Passenger survival patterns
* Gender wise survival analysis
* Passenger class distribution
* Family size impact on survival
* Age and fare distribution
* Feature engineering for ML models

---

## 📂 Dataset

* titanic.csv

Source: Kaggle Titanic Dataset

---

## 🛠️ Tools Used

* Python 3
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

---

## 📊 Analysis Performed

* Data Loading & Inspection
* Missing Value Analysis
* Null Value Handling
* Survival Analysis
* Passenger Class Analysis
* Gender wise Survival Analysis
* Age Distribution Analysis
* Fare Distribution Analysis
* Correlation Analysis
* Data Visualization using Seaborn

---

## ⚙️ Feature Engineering Performed

* Missing Value Imputation
* FamilySize Feature Creation
* IsAlone Feature Creation
* Title Extraction from Name
* Rare Title Grouping
* Label Encoding
* One-Hot Encoding
* Feature Selection
* Train-Test Split
* Feature Scaling using StandardScaler

---

## 🔍 Key Insights

* Female passengers had much higher
  survival rates than males
* Passengers in higher classes survived more
* Small families had better survival chances
* Passengers traveling alone had lower
  survival rates
* Younger passengers showed slightly
  better survival probability
