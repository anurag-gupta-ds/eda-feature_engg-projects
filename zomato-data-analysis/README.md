# 🍕 Zomato Dataset - Exploratory Data Analysis

Exploratory Data Analysis performed on the
Zomato restaurant dataset to find meaningful
insights about restaurants, ratings, cuisines,
and country wise distribution.

---

## 📌 Objective

To explore and analyze the Zomato dataset
and extract meaningful insights about:

- Restaurant ratings and distribution
- Country wise restaurant presence
- Top cuisines across different cities
- Online delivery and table booking trends
- Price range analysis

---

## 📂 Dataset

- Zomato.csv
- Country-Code.xlsx

Source: Kaggle Zomato Dataset

---

## 🛠️ Tools Used

- Python 3
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 📊 Analysis Performed

- Data Loading & Inspection
- Merging datasets (Zomato + Country Code)
- Handling Missing Values
- Country wise restaurant distribution
- Top cities with most restaurants
- Rating analysis and distribution
- Online delivery analysis
- Table booking analysis
- Top cuisines analysis
- Price range distribution
- Pie charts and bar plots

---

## 🔍 Key Insights

- India has the highest number of
  restaurants on Zomato
- New Delhi has the most restaurants
  among all cities
- North Indian cuisine is the most
  popular cuisine
- Most restaurants do not offer
  online delivery
- Majority of restaurants fall in
  the average price range
